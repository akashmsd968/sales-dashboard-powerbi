# Interactive Global Sales Performance Dashboard

An interactive Power BI dashboard that analyzes global sales data.

## Tools Used
- Power BI
- Power Query
- DAX

## What the project includes
- Data cleaning and transformation in Power Query
- Calculated columns and a structured data model
- DAX measures
- KPI cards, bar charts and donut charts
- Slicers for cross filtering

## How to open
Download `New project.pbix` and open it in Power BI Desktop.
